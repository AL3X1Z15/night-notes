NIGHT NOTES v1.0.1
Upload index.html, manifest.json, sw.js, icon-192.png and icon-512.png to the root of a new GitHub Pages repository. Enable Pages from the main branch / (root). Open the published HTTPS link in Safari on your iPhone, then use Share > Add to Home Screen. Keep the same URL to preserve access to local data. Visit online once to cache the app before trying offline.

Entries stay in browser storage on the device that recorded them. No automatic cloud sync; use Settings > Create JSON backup to save a copy to private iCloud Drive, and Restore from backup to recover. Verify the backup file exists. JSON backup files are not encrypted by the app. Do not upload personal backups to GitHub. Browser/device clearing can delete local data. CSV is for viewing data, not restoration.

Home and Morning show both dates; records are still keyed by the date they end; before 6 PM the default is today's date, after 6 PM tomorrow's date. Navigate manually if your schedule differs. Estimated sleep duration requires sleep onset, final wake-up and reported awake time (zero if no interruptions). Sample mode is separate and temporary.

In-chat prototype data and the original experimental version are not automatically migrated. Start fresh or retain earlier records separately. Test installation and restoration on your iPhone before relying on it.

Update an existing installation in place: back up on each device, replace index.html, sw.js and README.txt in the same repository/branch/folder, wait for Pages deployment, then reopen online. Do not clear site data or reinstall. Verify the v1.0.1 footer.

v1.0.1: date ranges and Return to tonight, Home opens the current sleep period, and explicit manual timestamp editor with date/hour/minute/AM-PM, preview, Save and Cancel. Storage key and schema remain unchanged.
